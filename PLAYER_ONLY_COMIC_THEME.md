# Player-only comic theme

Aura's application shell has been restored to the pre-cel-shading design from the white/gold loading-dance build.

Only the motion/robot viewers retain the stylized rendering language:
- toon/cel materials on the Unitree G1,
- illustrated crimson stages,
- subtle ink/halftone overlay,
- white/gold robot treatment,
- light-blue player labels/controls,
- stylized end-effector trails.

No generation, evaluation, discovery, benchmark, curation, or Solana logic was changed in this visual pass.
