# Unitree G1 model assets

The G1 URDF and STL geometry in this folder originate from Unitree Robotics' `unitree_ros` `robots/g1_description` package and are redistributed under the BSD 3-Clause License included as `LICENSE.txt`.

Aura uses `g1_29dof_mode_15.urdf` only as geometry / kinematic-description input for the browser visualization. The motion shown by Aura is an independent retargeted research visualization and is **not** an official Unitree controller, dynamics simulation, or statement that a trajectory is safe or executable on G1 hardware.
