# Inspect library update

The "Generate once. Inspect the result." section now includes two browsable groups:

- **Preloaded AIST++** — six bundled reference motions. Clicking one opens a retargeted G1 playback directly in the library detail viewer.
- **Aura generations** — saved NVIDIA Kimodo outputs evaluated by Aura, with the existing native playback, screening, comparison, review, and provenance tools.

AIST++ reference browsing is available even before the local generation server contains any saved Aura motions. Starter/reference clips remain separate from Aura's generated-motion preference-training dataset.
